# Page Nav — Sticky Section Menu Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a horizontal sticky nav that appears after the hero block, listing enabled sections with anchor links that highlight as the user scrolls.

**Architecture:** `navLabel()` on each block class drives which blocks appear; all block templates emit `id="{{ $block->block_type }}"` for anchor targeting; `welcome.blade.php` computes and renders the nav after the hero block; CSS + IntersectionObserver handle sticky behaviour and active state.

**Tech Stack:** Laravel Blade, vanilla JS (IntersectionObserver), SCSS/CSS custom properties, no new dependencies.

## Global Constraints

- No database changes
- No admin config
- Applies only to `welcome.blade.php` (page-builder storefront), not the legacy view
- All CSS lives in `resources/views/page-blocks/styles.blade.php`
- No Alpine.js, no extra build step — pure vanilla JS

- [ ] **Step 2: Update welcome.blade.php — compute nav links + render nav after hero**

Replace the current `@section('content')` block:

```blade
@section('content')
    @php
        $navLinks = $blocks
            ->filter(fn($b) => $b->is_enabled)
            ->map(fn($b) => [
                'href'  => '#' . $b->block_type,
                'label' => \App\PageBlocks\PageBlockRegistry::find($b->block_type)
                               ? \App\PageBlocks\PageBlockRegistry::find($b->block_type)::navLabel()
                               : null,
                'type'  => $b->block_type,
            ])
            ->filter(fn($l) => $l['label'] !== null)
            ->values();
    @endphp

    <div class="sf-blocks">
        @foreach($blocks as $block)
            <x-page-block :business="$business" :block="$block" />
            @if($block->block_type === 'hero' && $navLinks->count() >= 2)
                <nav class="sf-page-nav" aria-label="Sezioni">
                    @foreach($navLinks as $link)
                        <a href="{{ $link['href'] }}"
                           class="sf-page-nav-link"
                           data-section="{{ $link['type'] }}">{{ $link['label'] }}</a>
                    @endforeach
                </nav>
            @endif
        @endforeach
    </div>

    <a href="{{ route('booking.create') }}" class="sf-sticky-book sf-btn">Prenota un appuntamento</a>
@endsection
```

- [ ] **Step 3: Add JS to welcome.blade.php @push('scripts')**

Add a new `(function(){...})()` block at the end of the existing `@push('scripts')` section, after the sticky-book observer:

```js
(function () {
    var sfNav = document.getElementById('sf-nav');
    if (sfNav) {
        document.documentElement.style.setProperty('--sf-nav-h', sfNav.offsetHeight + 'px');
    }

    var links = document.querySelectorAll('.sf-page-nav-link');
    if (!links.length) return;

    var sectionMap = {};
    links.forEach(function (link) {
        var section = document.getElementById(link.dataset.section);
        if (section) sectionMap[link.dataset.section] = { link: link, section: section };
    });

    var observer = new IntersectionObserver(function (entries) {
        entries.forEach(function (entry) {
            var key = entry.target.id;
            if (sectionMap[key]) {
                sectionMap[key].link.classList.toggle('is-active', entry.isIntersecting);
            }
        });
    }, { rootMargin: '-20% 0px -60% 0px' });

    Object.values(sectionMap).forEach(function (item) {
        observer.observe(item.section);
    });
})();
```
